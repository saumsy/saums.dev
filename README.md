# [saums.dev](https://saums.dev)

## Stack

- Svelte + SvelteKit
- Tailwind CSS

## Running locally

This application requires `Node.JS` (>= 24) and `pnpm` to run.

```zsh
git clone https://github.com/saumsy/saums.dev
cd saums.dev
pnpm i
```

Running the app in developer mode:-

```zsh
pnpm dev
```
